# CS2 Demo Desk：下载比赛录像，通过 Steam 一键回放

复盘 CS2 时，找到录像只是第一步。下载、解压、找到文件，再输入播放命令，往往要来回切换几个窗口。CS2 Demo Desk 是一款面向 Windows 的中文录像下载工具，把比赛记录、下载队列、本地录像和启动回放放在同一个界面中。

这次发布的 **1.2.6** 增加了回放按键编辑页面：常用播放操作可以直接绑定按键，保存后自动生成 CFG，并随一键播放加载。

## 个人比赛、完美平台和赛事录像

个人官匹页面默认获取最近一周的比赛记录，可以刷新或调整时间范围。完成 Steam 官方页面登录后，软件在本机加密保存可用登录凭证，供下次尝试继续获取记录；凭证过期时需要重新登录。

完美平台页面支持通过官方登录流程自动获取平台凭证，获取近期个人比赛，并将可用 Demo 加入下载队列。无需每次手动复制密钥。近期版本也修复了有效凭证仍被拒绝、请求记录数量不兼容和比赛日期识别等问题。

赛事中心从 HLTV 获取已结束比赛，按赛事整理，并支持按队伍、日期和状态筛选。选择比赛下载时，再查找来源提供的 Demo 地址。来源尚未发布录像、录像过期或网站要求验证时，界面会提示当前状态；扩大日期范围并不保证所有历史录像仍可下载。

## 解压后，通过 Steam 自动播放

在“本地 Demo 库”选择录像，点击“一键播放”或“解压并播放”。软件会准备游戏目录内的录像副本，通过 **Steam 游戏 730** 启动 CS2，并执行本次回放配置。

游戏启动后自动进入所选录像，不需要再打开控制台输入播放命令。Steam 如果弹出启动选项确认，确认后即可继续。自动播放流程已经通过真实游戏日志和实际画面确认。

开始前请退出正在运行的 CS2，以便 Steam 应用本次播放参数。准备副本需要游戏所在磁盘有足够空间；下载原件会保留。

## 新增回放按键编辑页面

左侧打开“回放按键”，可以设置以下常用操作：

- 暂停或继续播放、打开播放面板。
- 慢速、正常速度和倍速播放。
- 切换透视、切换观察玩家或视角。

每项操作可以选择按键和指令，也可以增加、删除操作或恢复默认配置。重复绑定同一个按键时，软件会提示修改，避免配置相互覆盖。

点击“保存并更新 CFG”后，软件自动生成独立的 `demodesk_controls.cfg`。下一次从软件一键播放时，配置会写入游戏目录并自动加载；还可以展开预览，查看生成的内容。

修改不会打断当前正在播放的录像。新绑定会替换游戏中同名按键的功能，游戏也可能保存这些键位，因此建议使用闲置按键。取消绑定或关闭自动加载不会恢复原有键位，需要时可在游戏设置中调整。

## 本次验证与后续反馈

1.2.6 已通过 71 项基础测试、回放按键页面测试，以及 Windows 便携版启动和 CFG 保存测试。新增快捷键尚未逐项完成游戏内实测，遇到不生效的操作，可以在 GitHub 提交问题，并注明软件版本、按键和对应指令。

CS2 Demo Desk 是独立项目，与 Valve、Steam、完美平台或 HLTV 无隶属关系。希望它能减少复盘前的准备步骤，让找到录像之后的操作更直接。
