# CS2 Demo Desk 1.3.2 更新说明

本次修复 POV 录制开始前的游戏控制流程，仍使用本项目独立实现的工作室及用户本机 OBS。发行文件为 `CS2-Demo-Desk-Setup-1.3.2-x64.exe` Windows 安装程序。

## 修复内容

- 首次启动 PowerShell 并编译输入辅助程序的等待上限从 15 秒增加到 60 秒，给游戏加载和较慢的电脑留出时间。
- 控制失败时显示具体的中文原因；不将完整命令、命令行参数或编码后的游戏输入写到错误提示中。
- 首条控制指令初始化本次游戏的 Console 日志，让执行确认写入独立日志，再检查起始 Tick 和玩家视角。
- 优先从本次录制校验令牌认证、最近 5 秒内更新的 GSI 玩家列表取得目标 SteamID 的 `observer_slot`，按槽位切换，避免匿名或重名玩家导致昵称匹配失效；若缺少有效槽位而尝试昵称，仍须通过实际玩家 SteamID 校验后才能录制。
- 切换目标玩家前关闭自动导播，并选择第一人称观察模式；切换后继续等待新 GSI 状态确认身份，录制期间持续检查所选 SteamID。
- 所选玩家视角确认后，开始录制前隐藏 DemoUI，减少回放面板遮挡。

录制期间仍通过游戏日志和 GSI 验证实际进度及所选玩家视角。意外跳转、提前暂停、视角变化或确认失败时停止任务，并保留已产生的未完成素材。

## 使用

连接本机 OBS WebSocket，选择用于录制 CS2 的场景，再选择玩家和片段开始录制。游戏通过 Steam 游戏 730 启动；如果 Steam 显示启动确认，请确认后等待载入。控制台按键应保留默认 ~，游戏与 Demo Desk 应使用相同权限。

首次控制可能需要等待最多 60 秒。录制期间不要手动暂停、切换视角或关闭游戏；任务报告错误后先检查 OBS 连接、游戏窗口、控制台按键及权限，再重试。
