# CS2 Demo Desk 1.2.8

在“偏好设置”新增三个独立开关，默认关闭：

- **开机自动启动**：登录 Windows 后打开软件，使用便携版 EXE 的固定路径。
- **启动后自动下载未下载的比赛 Demo**：先刷新所选来源，再下载当前日期范围内未完成的录像；可分别勾选官匹、完美平台和职业赛事。
- **下载完成后自动退出**：任务全部成功后，倒计时 10 秒退出；可在界面取消本次退出。

已完成、已取消及日期未知的比赛会跳过，失败记录每次启动最多自动尝试一次。暂停、失败、来源需要登录/验证或获取不完整时会保留窗口；获取、解压和回放准备进行中不会退出。自动下载无新任务时也会退出，仅关闭本软件。

请先登录所需来源，并设置各页面的日期范围。便携版请放在固定位置，更换 EXE 或移动位置后重新开启开机启动。

验证：76 项基础测试、启动下载与退出端到端测试、Windows 启动项 API 写入/读取/移除测试通过。未进行真实重启测试。本版本未签名。
