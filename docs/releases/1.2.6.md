# CS2 Demo Desk 1.2.6

Windows x64 便携版，下载 EXE 后运行。

## 本次更新

- 新增“回放按键”页面：选择常用播放指令、修改操作名称和按键、增加或移除操作、恢复默认、查看 CFG。
- 保存后自动更新独立的 `demodesk_controls.cfg`，下次一键播放自动加载；重复按键会提示修正。
- 一键播放通过 Steam 启动游戏 730，使用游戏目录内的录像副本和配置自动回放，无需手动输入控制台命令。
- 包含自 1.1.0 以来的完美平台自动登录、凭证本机加密保存、比赛获取及请求兼容性修复。

## 使用方法

1. 退出旧版下载工具，运行新 EXE。
2. 打开“回放按键”，设置键位，点击“保存并更新 CFG”。
3. 在“本地 Demo 库”点击“一键播放”或“解压并播放”。如 Steam 提示启动确认，请确认。

播放前需退出已运行的 CS2，才能使用本次启动参数。修改按键在下次启动回放时生效；绑定会替换同名游戏按键，关闭此功能不会恢复原有键位。
