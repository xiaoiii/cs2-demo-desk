# CS2 Demo Desk 1.2.11

下载后自动解压并把 **.dem 直接保存到 CS2 的 game/csgo/replays**。官匹、完美平台和赛事的 BZ2、ZIP、RAR、7z 均支持；直接下载的 DEM 也保存到录像目录。

- 自动查找 Steam 游戏库中的已有录像目录；找不到时提示选择，保存后下次继续使用。
- 偏好设置新增“Demo 录像目录”，顶部和底部快捷栏可直接打开。
- 同名录像自动另存，不覆盖；原压缩包保留，取消选目录或出错后可重试保存。
- 自动退出等待解压及保存完成；升级保留历史路径，不搬迁已有文件。

Windows x64 便携版。请先退出旧版，再运行新版。此版本未签名。

验证：87 项基础测试、16 项桌面回归，以及打包版自动保存、目录选择、失败重试和成功后自动退出测试通过。
