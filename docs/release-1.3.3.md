# CS2 Demo Desk 1.3.3 更新说明

本次修复真实 OBS 与 CS2 联录中发现的结束位置误判和回放面板重复打开问题。发行文件为 `CS2-Demo-Desk-Setup-1.3.3-x64.exe` Windows 安装程序，继续使用本项目独立实现的工作室及用户本机 OBS。

## 修复内容

- CS2 使用 `demo_step_tick` 自然播放片段后，暂停日志可能比目标晚几个 Tick。现在仅接受目标前 1 Tick 至目标后 4 Tick 的暂停位置，避免正常播放到目标后的帧边界被误判为失败。按 64 Tick/s 计算，允许的尾部最多为 62.5 毫秒；提前更多或超过尾部上限，仍会停止并将素材标记为未完成。
- 素材保留实际结束位置 `actualEndTick`，不将允许的尾部偏差改写成恰好停在目标 Tick。
- 开始录制前使用 `demo_ui_mode 0` 明确关闭回放面板。玩家视角需要再次校准时也保持关闭，避免 DemoUI 的切换行为重新打开控制条。

录制仍须先确认实际玩家 SteamID，录制中持续检查身份、游戏状态和真实 Tick。意外跳转、视角变化或校验失败会停止任务，已产生的素材会保留为未完成。

## 使用

连接本机 OBS WebSocket，选择用于录制 CS2 的场景，再选择玩家和片段开始录制。游戏通过 Steam 游戏 730 启动；如果 Steam 显示启动确认，请确认后等待载入。控制台按键应保留默认 ~，游戏与 Demo Desk 应使用相同权限。

录制期间不要手动暂停、切换视角或关闭游戏。首次控制可能需要等待 PowerShell 启动，最多 60 秒。

## 验证范围

修复后的真实短片重录通过。指定玩家的两次击杀片段范围为 DEM Tick 8766–9281，约 8.05 秒；实际结束于 DEM Tick 9282，任务完成且素材标记为完整，并保留实际结束 Tick。输出 MP4 为 13.85 秒、1920×1080 / 60fps、H.264 视频与 AAC 游戏音频，原始素材长度包含开始播放前的准备画面。

完整视频解码通过，黑屏检测未发现整体黑屏；抽帧确认目标玩家击杀画面及关闭的底部回放控制条。128 项自动测试通过。测试结束后通过游戏 `quit` 正常关闭，退出日志记录 `HSR_QUIT`、`EventAppShutdown`、`MainLoop returning` 和 `Source2Shutdown`，CS2 进程已退出，本次 GSI 配置已删除。该退出操作用于本次测试清理，录制完成后软件仍保留用户的游戏。

16 项桌面下载回归通过。1.3.3 安装程序实际安装成功，安装后的真实 DEM 分析、地图回放、语音活动及工作室页面验证通过，安装版本与录制源码核对一致。详细结果见发行文件中的 [TEST-REPORT.md](../TEST-REPORT.md)。本次只验证上述短片，整场 POV 尚未实测。
